# Zavyx VE app icon

A violet rounded square (Zavyx violet, `#8b6cff` to `#5b34e6`) with a white "Z".
128 px and up add "VIDEO / EDITOR"; smaller sizes add a play button instead.

Regenerate every file (and its `.attribution` sidecar) with `python zavyx/gen_assets.py`.
The file names are Zavyx VE's, so the code and packaging find them unchanged.
