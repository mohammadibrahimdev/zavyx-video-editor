# Security

Zavyx VE opens media and project files from anywhere, so a file that crashes it or makes it
misbehave is a security problem. Please report it privately instead of in a public issue:

- Use GitHub's **[private vulnerability report](https://github.com/mohammadibrahimdev/zavyx-video-editor/security/advisories/new)**.
- Say which version you use (Help ▸ About), what you did, and attach the file only if it is safe
  to share.
